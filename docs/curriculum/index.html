Roadmap

The course teaches the autonomous agent loop as a system: chapters grouped into modules, each ending with exercises, a practice bank, interview prep, and (where the curriculum map assigns one) a project. Hands-on chapters that need a real model run against Ollama by default — zero API cost, zero API key — with a documented option to swap in a hosted provider instead.

Module 1: Foundations of the Agent Loop — Complete

What makes something an "agent" instead of a single model call, and how to break a goal into steps.

Outcome: build and run a minimal agent loop; decompose and re-plan a multi-step goal.

Module 2: Giving Agents Capabilities — Complete

Tool use and memory — how an agent acts on the world and carries state across steps.

Outcome: design a tool-calling interface with real error handling; design a memory architecture with a defensible short-term/long-term split.

Module 3: Making Agents Reliable — Complete

An agent that notices and corrects its own mistakes, and stays inside safe bounds while doing it.

Outcome: add a reflection/self-correction loop; design guardrails mapped to specific failure modes.

Module 4: Measuring and Controlling Agents — Complete

Knowing whether an agent is actually working, and keeping it affordable and fast.

Outcome: design a reliability/observability plan; apply cost- and latency-control techniques.

Module 5: Multi-Agent Systems — Complete

When and how to coordinate more than one agent, and running one in production.

Outcome: choose and implement a multi-agent coordination pattern; operate an agent system in a production-shaped setting.

Module 6: Architecture and Capstone — Planned

Architect-level synthesis — designing and defending a complete agent system.

Outcome: design and defend a complete autonomous agent system architecture.

Chapter Path

Chapter 1 — Live

The Agent Loop: Building Your First Autonomous Agent

Perception, reasoning, action, observation — the loop every agent in this course builds on.

 Chapter 2 — Live

Planning and Task Decomposition

Breaking a goal into steps, re-planning on failure, fixed plans vs. emergent ReAct-style planning.

 Chapter 3 — Live

Tool Use and Function Calling

Choosing the right tool, forming correct arguments, and handling tool failure.

 Chapter 4 — Live

Memory and State

Short-term working memory vs. long-term persisted memory, and their real engineering trade-offs.

 Chapter 5 — Live

Reflection and Self-Correction

An agent noticing and fixing its own mistakes, as a designed architectural component.

 Chapter 6 — Live

Guardrails and Safety for Autonomous Agents

Iteration bounds, human approval, sandboxing, and rate limiting, mapped to the failures each one stops.

 Chapter 7 — Live

Evaluating Agent Reliability

Task-success rate, trajectory/tool-call correctness, multi-turn drift, non-determinism (pass@k), and cost-per-success -- a real agent eval harness.

 Chapter 8 — Live

Cost and Latency Control of Agent Loops

Iteration bounding, model tiering, caching, and early exit for a bounded, affordable agent loop.

 Chapter 9 — Live

Multi-Agent Orchestration Patterns

Supervisor/worker dispatch, sequential pipelines, parallel fan-out/fan-in, blackboard coordination, failure isolation, and cross-agent trajectory evaluation.

 Chapter 10 — Live

Multi-Agent Coordination and Communication

Peer-to-peer message passing over a shared message bus, and the new failure modes: miscommunication, duplicated work, and deadlock.

 Chapter 11 — Live

Operating Agents in Production

Retries, timeouts, structured logging, and operating a multi-agent system for real.
Chapter 12 — Planned

Designing Agent Architectures

Architect-level synthesis: choosing a full agent architecture for a given problem.

Chapter 13 — Planned

Capstone: Designing and Defending an Autonomous Agent System

A Level 4 architecture challenge composing loop design, planning, tools, memory, guardrails, evaluation, and cost control into one system.

Chapters 1-6 are live end to end (Modules 1, 2, and 3 all complete). Chapters 7-13 are scaffolded (.gitkeep'd directories under chapters/) and planned per CURRICULUM_MAP.md, not yet built — see PROJECT_STATE.md for the current, authoritative build status and the next recommended session's task.
