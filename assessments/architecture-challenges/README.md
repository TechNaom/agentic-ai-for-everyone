# Architecture Challenges: Chapter 13's Capstone Rubric

Per `docs/curriculum/CURRICULUM_MAP.md`, Module 6's stated assessment
is **"architecture-design exercise (Ch. 12) + capstone rubric (Ch. 13,
architecture challenge, Level 4)"** — two separate deliverables.
`assessments/module-assessments/module-6-architecture-design-exercise/`
already shipped the first (scoped to Chapter 12 alone, on a sixth
scenario, Alderwood Transit Cooperative). This directory holds the
second: the grading rubric for Chapter 13's own L4 Architecture
Challenge.

`assessments/architecture-challenges/` was scaffolded from this
repo's very first session and confirmed, in
`quality-audits/chapter-12-audit.md`, as reserved specifically for
this deliverable — not `module-assessments/`, which follows every
prior module's own `module-N-*-exercise/` naming convention instead.

## What's graded, and where it lives

Unlike every Chapter 1-12 module assessment (which pairs a
`solution.py`/`starter.py` with its own fresh scenario), Chapter 13's
own L4 capstone has NO separate lesson-vs-project split — the
deliverable being graded is Chapter 13's OWN
`chapters/chapter-13-capstone-designing-and-defending-an-autonomous-
agent-system/project/solution.py` (Thornwick Marketplace Collective),
walked through in that chapter's own `lesson.html`. This directory
does not duplicate that scenario or ship a second one — it holds only
the grading instrument, `RUBRIC.md`, applied to that one deliverable.

## How to use this rubric

1. Read `chapters/chapter-13-capstone-designing-and-defending-an-
   autonomous-agent-system/project/README.md` for the full problem
   statement.
2. Attempt your own characterization, mechanism selection, budget,
   implementation, and instrumentation for Thornwick Marketplace
   Collective — no scaffold, no starter file, per L4's own
   "business/system problem only" definition.
3. Run your own harness and confirm it actually meets the budget you
   stated.
4. Compare your work against that chapter's own `project/solution.py`
   (scores 14/14) and self-grade against `RUBRIC.md` below.

## Files

- `RUBRIC.md` — the five-criterion grading rubric for the L4
  capstone deliverable.
