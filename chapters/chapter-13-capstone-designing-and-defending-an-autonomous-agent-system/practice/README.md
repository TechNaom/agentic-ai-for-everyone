# Chapter 13 Practice Bank: Capstone — Designing and Defending an Autonomous Agent System

Eight short, independent scenarios — each a different fictional
**multi-component** system being architected at capstone scale, each
testing whether you can correctly name ONE decision-framework concept
from a short description. Abstract system names (RouteDesk, ClaimGate,
StockMesh, etc.), not full organizations, matching Chapter 12's own
practice-bank convention for quick diagnostic scenarios.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N` with your own short answer, then re-run.

## Files

- `starter.py` — all eight answers blank; scores 0/8 with no crash.
- `solution.py` — the fully filled-in reference; scores 8/8.
- `index.html` — the browsable version of this page.
- `ai-paired.html` — a solo-build-then-critique exercise using a
  ninth scenario.
