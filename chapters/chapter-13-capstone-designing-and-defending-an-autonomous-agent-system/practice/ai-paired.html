Chapter 13 Practice — Solo → AI-Paired → Critique 15 min

Now Pair With an AI

A ninth scenario, "QuotaSpan" (an unnamed employer's internal tool, matching this course's own convention for a quick diagnostic left generic): it runs a document-intake component and a compliance-review component, both writing to the SAME shared case file, with the review step gating an irreversible filing action. First decide, yourself, whether this needs multi-agent, which mechanisms are load-bearing, and whether anything looks like a smell. Then ask an AI assistant for the same snap judgment and compare.

A reference prompt

Show a strong version of this prompt 
QuotaSpan has a document-intake component and a compliance-review component that both write to the SAME shared case file, and the review step gates an irreversible filing action. In one pass: (1) state whether this needs multi-agent and the specific fact that decides it; (2) name every Chapter 1-11 mechanism that's load-bearing and why; (3) run an architecture-smell check against your own selection and report any flags.

Review checklist

What a rushed answer tends to miss
  • Does it correctly identify that writing to the SAME shared case file, with no concurrent independent actors, does NOT by itself justify peer communication (Ch10) -- the two components can still be sequential, not racing?
  • Does it name the guardrail as load-bearing BEFORE naming anything else, since the irreversible filing action is the single highest-stakes fact here?
  • Does it actually run a smell check against its own selection, or just assert the design is correct with no cross-check?
