# Chapter 11 Practice Bank: Operating Agents in Production

Eight short, independent scenarios — each a different fictional
production-operating system (a retry dock, a backoff queue, a wire
watch, a loop guard, a stalled exchange, an event trail, a morning
report, and an attribute-after tool) — each testing whether you can
correctly name one operating mechanism or failure mode from a short
description. Faster and more varied than the Exercises, on purpose:
the goal here is pattern recognition across many systems, not depth
on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
