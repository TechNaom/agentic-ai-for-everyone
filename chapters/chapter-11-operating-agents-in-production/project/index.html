Chapter 11 Project (Chapter Mini-Project) ~60 min, hands-on

Project: An Overnight Operating Harness for Wrenfield Dispatch Alliance

This is a chapter mini-project, not one of this course's numbered L1-L4 projects — the L3 Independent project was deferred past Chapter 8, 9, and 10; this session's decision on it is recorded in quality-audits/chapter-11-audit.md and PROJECT_STATE.md. Scenario: Wrenfield Dispatch Alliance, a fictional regional freight alliance, wants ClaimScout and ShipScout -- two genuine PEER agents, not a supervisor and a worker -- confirming shipment dispatches overnight, unattended, the same way the lesson's DockScout and YardScout coordinated shipments during the day.

The three pillars, combined
  • Idempotent commits — a side effect's key is built from the fields that define it, so a retried call never commits twice.
  • Bounded retries — a flaky call is retried a fixed number of times with exponential backoff, every attempt logged.
  • Crash-survivable run summary — the night's success/failure numbers are computed by re-parsing the structured log, not from in-memory counters.
