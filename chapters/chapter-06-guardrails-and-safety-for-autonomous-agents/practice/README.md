# Chapter 6 Practice Bank: Guardrails and Safety for Autonomous Agents

Eight short, independent scenarios — each a different fictional system
(a parking-garage gate bot, a payroll bot, a data-center ops bot, a
support-ticket bot, a bulk-mail bot, an approval bot, a record-deleting
memo bot, and a shipment bot) — each testing whether you can correctly
identify one guardrail concept or failure type from a short
description. Faster and more varied than the Exercises, on purpose: the
goal here is pattern recognition across many systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
