# Chapter 1 Practice Bank: The Agent Loop

Eight short, independent scenarios — each a different fictional
system (an email triage tool, a hotel front desk, an auto shop, a
delivery service, a restaurant, a code-review agent, a flaky network,
and a framework-heavy build) — each testing whether you can correctly
identify one agent-loop concept or failure type from a short
description. Faster and more varied than the Exercises on purpose: the
goal here is pattern recognition across many systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
