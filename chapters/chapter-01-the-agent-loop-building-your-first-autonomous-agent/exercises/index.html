Chapter 1 Exercises ~40 min, hands-on

Exercises: The Agent Loop

These exercises use a second scenario, deliberately different from the lesson's Northbeam Outdoors/TrailBot hook: Summit Gear Co-op, a fictional camping-gear rental shop. Its agent, GearBot, answers questions using two tools: check_availability (is an item in stock) and get_rental_price (its daily rental price). Applying this chapter's concepts to a fresh scenario is the point.

Exercise standard Eight tasks total, worth 17 points. Five are marked production-gear — writing a real tool schema, fixing a real wrong-argument bug, implementing a real iteration guard, diagnosing a real failure trace, and adding a real timeout budget, not just concept recall.

Tasks

  1. Map failures to loop concepts — assign perception, reasoning, action, observation, or guard to five GearBot failures.
  2. Loop-dependency reasoning — does a missing observation make a runaway loop more or less likely?
  3. (Production-gear) Tool schema — describe get_return_date as a real JSON schema.
  4. (Production-gear) Normalize fix — tolerate a realistic wrong-argument variation.
  5. (Production-gear) Iteration guard — make a loop halt on a model that never stops.
  6. (Production-gear) Failure diagnosis — correctly name a hallucination-despite-observation failure.
  7. (Production-gear) Timeout budget — raise TimeoutError past a budget.
  8. Completeness check — confirm all five loop concepts were actually used.

Full instructions and the scoring rubric are in README.md alongside starter.py (fill in the TODOs) and solution.py (the reference, scores 17/17).
