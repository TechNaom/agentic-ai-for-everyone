Project: Build and Trace a Minimal Agent Loop

Wavecrest Marina wants SlipBot, an agent that answers boat-slip availability questions using one tool, check_slip_availability(slip_id). Complete the three-TODO run_agent() scaffold in starter.py so it correctly runs the perception, reasoning, action, observation loop from the lesson — including surviving a model that never stops requesting a tool.

Why a fake model, not live Ollama This project is gradable the same way everywhere, including CI with no Ollama server running. A deterministic FakeModel plays both the happy path and the runaway-loop failure mode from Section 10 of the lesson. Once your self-check passes, README.md shows how to swap in the real openai-against-Ollama client for the full live experience.

The three TODOs

  1. TODO 1 — recognize a final answer (no tool_calls) and return it.
  2. TODO 2 — execute every requested tool call, trace it, and feed the observation back in.
  3. TODO 3 — the guard: halt cleanly at max_iterations.
