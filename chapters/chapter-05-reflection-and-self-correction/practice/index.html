Practice Bank: Reflection and Self-Correction

Eight short, independent scenarios, each a different fictional system — a car wash pricing bot, a fitness advisor, a customer- support bot, an estimate bot, a form bot, an email-drafting audit bot, a looping self-corrector, and a math "double-check" bot. Each tests whether you can correctly identify one reflection concept or failure type from a short description. Faster and more varied than the Exercises, on purpose: pattern recognition across many systems, not depth on one.

Practice standard Eight scenarios, one answer each, scored automatically. Full text of each scenario is in starter.py.
