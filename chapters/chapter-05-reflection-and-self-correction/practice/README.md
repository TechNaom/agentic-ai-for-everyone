# Chapter 5 Practice Bank: Reflection and Self-Correction

Eight short, independent scenarios — each a different fictional system
(a car wash pricing bot, a fitness advisor, a customer-support bot, an
estimate bot, a hours-lookup form bot, an email-drafting audit bot, a
looping self-corrector, and a math "double-check" bot) — each testing
whether you can correctly identify one reflection concept or failure
type from a short description. Faster and more varied than the
Exercises, on purpose: the goal here is pattern recognition across
many systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
