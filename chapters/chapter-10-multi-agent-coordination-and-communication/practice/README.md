# Chapter 10 Practice Bank: Multi-Agent Coordination and Communication

Eight short, independent scenarios — each a different fictional
peer-to-peer agent system (a relay desk, an inbox guard, a shift
planner, a lot tracker, a wait loop, a clock guard, a roster rule, and
an exchange log) — each testing whether you can correctly name one
communication pattern or failure mode from a short description. Faster
and more varied than the Exercises, on purpose: the goal here is
pattern recognition across many systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
