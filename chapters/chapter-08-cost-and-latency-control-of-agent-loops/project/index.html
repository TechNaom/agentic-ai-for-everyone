Project: A Cost-Controlled Harness for YieldScout

This is a chapter mini-project, not one of this course's numbered L1-L4 projects — the L3 Independent project ships AFTER this chapter, not during it. Scenario: Portage Grain Cooperative, a fictional grain-storage cooperative, wants YieldScout built the same way the lesson's FactScout was cost-controlled.

The three pillars, combined
  • Task success — forgiving, order-independent: did the (possibly budget-truncated) trace include check_inventory_level and the right ending tool for this silo.
  • Fail-closed budget — both a step cap AND a dollar-cost cap must be respected; exceeding either one denies the step.
  • Cost-controlled harness — runs each task 20 times, applying the budget per step, and reports the resulting success rate and total cost on top of which cost_per_success can be computed.

The three TODOs

  1. TODO 1 — task_success()
  2. TODO 2 — is_within_budget()
  3. TODO 3 — run_cost_controlled_harness()

How to run it

terminal
python3 starter.py

Prints a structural self-check: 9 checks across task success, the fail-closed budget, and the aggregate cost-controlled harness.

Files

  • starter.py — the scaffold with 3 # TODOs and the self-check.
  • solution.py — the fully filled-in reference; passes all 9 checks.
  • RUBRIC.md — self-grading criteria.
  • ai-paired.html — a solo-build-then-critique exercise using a fourth scenario.
