# Chapter 8 Practice Bank: Cost and Latency Control of Agent Loops

Eight short, independent scenarios — each a different fictional agent
(a monitoring bot, a summarizing bot, a lookup bot, an archive bot, a
fetch bot, a monitor bot, a retry bot, and a savings-reporting bot) —
each testing whether you can correctly identify one cost/latency-
control technique or risk from a short description. Faster and more
varied than the Exercises, on purpose: the goal here is pattern
recognition across many systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
