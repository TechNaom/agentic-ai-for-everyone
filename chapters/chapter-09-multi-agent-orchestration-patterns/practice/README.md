# Chapter 9 Practice Bank: Multi-Agent Orchestration Patterns

Eight short, independent scenarios — each a different fictional
multi-agent system (a help desk, a document pipeline, a pricing desk,
a project board, a fleet operator, a ticket router, an order desk, and
a status bot) — each testing whether you can correctly name one
coordination pattern or failure mode from a short description. Faster
and more varied than the Exercises, on purpose: the goal here is
pattern recognition across many systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
