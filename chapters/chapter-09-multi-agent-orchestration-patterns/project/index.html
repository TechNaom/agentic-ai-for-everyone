Chapter 9 Project (Chapter Mini-Project) ~60 min, hands-on

Project: A Supervisor Harness for CityScout

This is a chapter mini-project, not one of this course's numbered L1-L4 projects — the L3 Independent project was deferred past Chapter 8 and is still not yet built as of this chapter (not built here either; see PROJECT_STATE.md). Scenario: Ashgrove Municipal Services, a fictional municipal building-services office, wants CityScout built the same way the lesson's TripScout was coordinated.

The three pillars, combined
  • Fail-closed routing — the router returns the highest-scoring worker, UNLESS the score is 0, in which case it returns None rather than guessing.
  • Failure isolation — every worker call runs inside a try/except boundary; an exception never propagates to the supervisor.
  • Idempotent, attributed harness — skips a duplicate (subtask, worker) dispatch, and reports which agent was first responsible for any failed case.
