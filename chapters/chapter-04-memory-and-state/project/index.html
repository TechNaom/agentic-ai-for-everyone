Project: Multi-Tool Memory Agent for CareBot

Hollowridge Wellness Clinic wants CareBot, a scheduling and intake assistant combining multi-tool dispatch (checking appointment availability and booking a follow-up) with persisted long-term memory (a patient's conditions and preferences, correctly merged into a LATER, separate visit's working context). Complete the three-TODO scaffold in starter.py so both halves work correctly and compose into one end-to-end visit flow.

This IS one of this course's numbered projects Per docs/curriculum/CURRICULUM_MAP.md's project ladder, this is the L2 Assisted project — "build a multi-tool agent with memory and a reflection step... ships after Ch. 4, extended through Ch. 5-6." Chapter 4 ships the multi-tool- plus-memory half in full. The reflection half is a clearly labeled no-op passthrough (reflect_on_response()), already wired into the call path, waiting for Chapter 5 to fill in its body — see README.md for exactly why that's the honest approach rather than building reflection early or faking it.

The three TODOs

  1. TODO 1 — build_working_context(): merge a patient's persisted conditions/preferences into a fresh session's working memory.
  2. TODO 2 — promote_worthy_and_persist(): classify and persist promote-worthy facts stated during the visit, via read-modify-write.
  3. TODO 3 — run_visit_session(): compose the merge, tool dispatch, and promotion into one visit flow, calling the given reflect_on_response() at its labeled call site.
