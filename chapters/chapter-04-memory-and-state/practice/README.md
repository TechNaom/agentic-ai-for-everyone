# Chapter 4 Practice Bank: Memory and State

Eight short, independent scenarios — each a different fictional system
(a hotel concierge, a financial advisor, a tutoring service, a new-hire
onboarding portal, a meal-kit profile service, a fitness coach, a
therapy practice, and a summarization-only assistant) — each testing
whether you can correctly identify one memory concept or failure type
from a short description. Faster and more varied than the Exercises,
on purpose: the goal here is pattern recognition across many systems,
not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
