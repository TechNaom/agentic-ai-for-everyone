Chapter 4 Practice — Solo → AI-Paired → Critique 15 min

Now Pair With an AI

A ninth scenario, not in the eight above: "MemoBot", a personal-assistant agent at a fictional productivity app (left unnamed on purpose, the same way Chapter 3's HandoffBot scenario did — a small scenario doesn't need an invented company). MemoBot persists a small set of durable facts per user (dietary restrictions, recurring reminders) to a JSON file, one file per user. Two real, layered problems were observed in the same trace. First: a user told MemoBot about a peanut allergy in one session; a second session, weeks later, recorded a new reminder preference — and the peanut allergy vanished from the store entirely after that second write, even though the second write never touched allergies at all. Second, in a completely different session: a user stated a new dietary restriction ("actually I'm vegetarian now too") midway through a single conversation, and MemoBot's own reply at the very end of that same conversation still didn't reflect it — even though the very next, separate session correctly showed the vegetarian restriction had been saved.

Step 1: Diagnose it yourself, first

Before reading further: name the two distinct problems here using this chapter's vocabulary (one is about a write silently destroying unrelated data; the other is about trusting a variable captured before a write instead of re-checking after it) and write your own fix for each. There's no grading here, just your own reasoning to compare against Step 3.

Step 2: Ask an AI assistant

Thought process: this scenario has two layered problems (a blind-overwrite merge bug AND a stale-snapshot bug), so the prompt needs to ask the AI to identify both, not just one — a shallow prompt like "why is my agent's memory broken" invites a single, incomplete answer, usually just whichever bug is described first.

Write the prompt you'd give an AI assistant:

Paste your prompt into your assistant of choice and compare its answer against the critique below.
Show a strong version of this prompt 
Here's my agent MemoBot, which persists a small set of durable facts per user (dietary restrictions, reminders) to a JSON file, one file per user: [paste the scenario above]. Identify EVERY distinct memory problem in this description, not just the first one you notice -- there are two -- and name each using this chapter's vocabulary (a read-modify-write / blind-overwrite merge bug, or a stale-snapshot bug where mid-session behavior uses a variable captured before a write instead of re-checking the store after it). Propose a concrete, specific fix for each.

Step 3: Critique what came back

What a complete diagnosis catches
  • Problem 1 (blind-overwrite merge bug): a write path that constructs a fresh facts dict (or only partially loads existing state) instead of loading the user's complete existing record first destroys unrelated fields it never intended to touch — the peanut allergy wasn't targeted by the reminder-preference write, but it was still lost, because the write never read the full existing record before saving. The fix is read-modify-write on the complete record, every time.
  • Problem 2 (stale-snapshot bug): code that decided the final reply used a `facts` variable captured at the start of the session, before the vegetarian-restriction message was ever processed — the write to disk succeeded (which is why the next session saw it correctly), but nothing mid-session re-checked the store after that write to inform the reply happening in the same turn.
  • A shallow AI answer often catches only Problem 1 (the more visible data-loss issue) and misses that Problem 2 is a separate, independent issue — fixing the merge bug alone doesn't make same-session behavior reflect a fact stated moments earlier, and vice versa.

Compare the AI's answer against your own Step 1 notes and the two-problem breakdown above. Did it catch both? Did it propose the right fix for each — read-modify-write on the full record, and a post-write re-check before deciding the reply — or did it conflate the two into one vague "fix the memory system" suggestion?
