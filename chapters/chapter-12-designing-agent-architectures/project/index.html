Project: Driftlight Energy Cooperative — the L3 Independent Project

This is this course's numbered L3 Independent project — not a chapter mini-project. L3's own definition: "design and implement a reliability-instrumented, cost-bounded agent for a given problem, no scaffold." It was due after Chapter 8 and was deferred, explicitly, across Chapters 9, 10, and 11 — five consecutive sessions. This session's decision to ship it here is recorded in quality-audits/chapter-12-audit.md.

There is deliberately no starter.py. L3 is "no scaffold" by definition — you're handed a problem statement, not a fill-in-the-blank file. Read the problem statement in README.md, attempt your own characterization, mechanism selection, budget, implementation, and instrumentation first, then compare against solution.py.

The problem, in short

Driftlight Energy Cooperative, a fictional energy co-op, runs a demand-response program: members pledge a kilowatt-hour curtailment amount at enrollment (a separate, earlier session), and Driftlight must dispatch curtailment requests and apply credits during later, unattended grid-load-spike events — referencing that on-file pledge correctly, crediting exactly once per event even if a call is retried, and gating large credits behind human approval.

What the reference solution proves, end to end

  1. Characterizes the problem (single-agent, with the deciding fact stated).
  2. Selects the five load-bearing mechanisms (memory, guardrails, reliability measurement, cost control, operating layer) and the three that are NOT (reflection, multi-agent dispatch, peer communication).
  3. States a reliability/cost budget (95% minimum task-success, 8-cent maximum cost per run).
  4. Implements a real MemoryStore, a fail-closed apply_credit guardrail, and an idempotent commit_once commit layer.
  5. Instruments all three task types with a deterministic harness and measures real task-success rates and cost-per-success against the stated budget.
  6. Assembles the Architecture Decision Record.

Files

  • RUBRIC.md — self-grading criteria.
