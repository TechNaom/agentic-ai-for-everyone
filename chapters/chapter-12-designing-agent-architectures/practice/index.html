Chapter 12 Practice Bank ~20 min

Practice Bank: Designing Agent Architectures

Eight short, independent scenarios, each a different fictional system being architected — SingleDesk, TwinField, VaultGate, ChatterMesh, NightWatch, DraftCritic, StakesLadder, and ReviewPacket. Each tests whether you can correctly name one decision-framework concept from a short description. Faster and more varied than the Exercises, on purpose: pattern recognition across many systems, not depth on one.

How to run

terminal
python3 starter.py

Fill in each ANSWER_N, re-run, and watch your score climb toward 8/8. solution.py is the fully filled-in reference and scores 8/8.

After this

See ai-paired.html for a solo-diagnosis-then-critique exercise using a ninth scenario.
