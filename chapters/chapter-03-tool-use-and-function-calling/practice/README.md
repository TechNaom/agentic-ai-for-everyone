# Chapter 3 Practice Bank: Tool Use and Function Calling

Eight short, independent scenarios — each a different fictional system
(a moving-company quote tool, a bookkeeping client-ID intake, a weather
radar lookup, a lending credit-check, a gym membership canceller, a
delivery dispatcher, a legal-clinic case tracker, and a ticket-booking
system) — each testing whether you can correctly identify one tool-use
concept or failure type from a short description. Faster and more
varied than the Exercises, on purpose: the goal here is pattern
recognition across many systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
