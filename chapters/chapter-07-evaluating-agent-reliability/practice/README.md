# Chapter 7 Practice Bank: Evaluating Agent Reliability

Eight short, independent scenarios — each a different fictional agent
(a delivery bot, an invoicing bot, a support-triage bot, a research
bot, a quoting bot, an audit bot, a scheduling bot, and a sorting bot)
— each testing whether you can correctly identify one eval concept or
failure type from a short description. Faster and more varied than the
Exercises, on purpose: the goal here is pattern recognition across many
systems, not depth on one.

## How to run

```bash
python3 starter.py
```

Fill in each `ANSWER_N`, re-run, and watch your score climb toward
8/8. `solution.py` is the fully filled-in reference and scores 8/8.
